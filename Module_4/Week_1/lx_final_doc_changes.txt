4️⃣ 30 Second Project Explanation for Judges
Our project is an Alexa conversational assistant called Zodiac Guide.

The skill identifies the user's zodiac sign from their birth date and provides personality traits, lucky color, lucky number, compatible signs and horoscope information.

The user can then receive a personalized book recommendation based on zodiac personality.

The skill also supports standard book recommendations using genre, age group and language preferences.

We implemented multiple intents, custom slots, CSV based knowledge storage, Lambda functions and session management to maintain conversational context across multiple turns.
